# Analyzing Chemical Plant Emissions and Accidents Across the U.S.

This program explores EPA TRI data to examine trends in pollutant emissions, safety incidents, and their relationship to location, industry, and regulations over time.

Important to note: Some non-contiguous US territories (Guam, Virgin Islands, American Samoa, Mariana Islands) are deleted from the raw data source. This is to make the heatmap functional. For the same reason, data from Eareckson Air Station in Alaska is removed.
